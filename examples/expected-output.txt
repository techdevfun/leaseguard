### 1. grant a 3-second lease for the deploy command
lease <id> granted
  pattern : echo deploy-*
  valid   : 3s (until <ts>)
  scope   : <tmpdir>
  note    : demo lease
  token   : <token>

run it with: leaseguard run --lease <token> -- echo deploy-<arg>

### 2. run it right away -> allowed
